# ChatGPT Prompt Templates - Repo

Questo repository raccoglie template pronti all'uso per ottimizzare l'utilizzo di **ChatGPT Free**, evitando di consumare gli slot file nei progetti.  
I template sono pensati per tre principali ambiti:

- **Creazione e correzione script**  
- **Generazione di guide procedurali da lista comandi**  
- **Analisi e troubleshooting di errori in produzione**

---

## Contenuto del repository

### 1. [Scripts](https://github.com/erbussola/PromptProjectChatGPT/blob/main/Scripts)
Template per **creare o correggere script** in Bash, Python o altri linguaggi di scripting.  
Include istruzioni dettagliate su come strutturare lo script, commentarlo e verificare eventuali dipendenze.

**Anchor:** `#scripts`

---

### 2. [Command2Guide](https://github.com/erbussola/PromptProjectChatGPT/blob/main/Command2Guide)
Template per **trasformare una lista di comandi in guide operative** passo-passo.  
Per ogni comando vengono aggiunte spiegazioni, note di attenzione e prerequisiti, con eventuali verifiche post-comando.

**Anchor:** `#command2guide`

---

### 3. [Troubleshooting](https://github.com/erbussola/PromptProjectChatGPT/blob/main/Troubleshooting)
Template per **analizzare errori in produzione** e generare una checklist di diagnostic e remediation.  
Fornisce cause probabili, comandi di verifica, soluzioni immediate e best practices per prevenzione.

**Anchor:** `#troubleshooting`

---

## Come usare i template

1. Cliccare sul link del file desiderato.  
2. Copiare il template nel prompt di ChatGPT all’interno del progetto.  
3. Personalizzare i placeholder con script, lista comandi o log da analizzare.  

---

## Note

- I template sono ottimizzati per il piano **Free** di ChatGPT, evitando di consumare i 5 slot file disponibili nei progetti.  
- Si consiglia di salvare sempre gli output finali in un repository esterno (Git, Notion) per avere backup e versionamento.
